# 자주 묻는 질문

[처음으로](../README.md) · [최신 버전](https://github.com/9root3/maple-mvp-releases/releases/latest)

## Git이나 Node.js도 설치해야 하나요?

필요 없습니다. Windows 설치 파일 하나만 받으면 됩니다.
GitHub 계정이나 별도 브라우저 확장도 필요 없습니다.

## 로그인은 어디서 하나요?

앱 오른쪽 위의 **로그인**을 누르면 메이플 경매장 창이 열립니다.
그 창에서 평소 사용하는 계정으로 로그인하고 캐릭터를 선택해 주세요.
연결되면 경매장 창은 숨겨지고 대시보드로 돌아옵니다.
자동으로 돌아오지 않으면 **연결 확인**을 누르면 됩니다.

웹 메이플 옥션은 200레벨 이상 캐릭터와 넥슨 OTP 이용 계정이 필요합니다.
이용 조건은 [메이플스토리 공식 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/394)를 참고해 주세요.

## 경매장 창을 닫아도 되나요?

연결되면 앱이 경매장 창을 숨깁니다. 계속 띄워 둘 필요는 없습니다.
다만 로그인 세션이 만료되면 다시 로그인해야 합니다.

## 시세 조회가 안 눌려요.

먼저 로그인과 캐릭터 선택을 마치고, 상단에 서버·캐릭터가 표시되는지 확인해 주세요.
연결이 확인되면 시세 조회를 사용할 수 있습니다.

## 검색 횟수는 어떻게 쓰나요?

현재 전체 목록은 정상 조회 기준 32회입니다.

| 조회 | 횟수 |
| --- | ---: |
| 전체 19종 최저 호가 | 19회 |
| 캐시 13종 체결 평균·건수 | 13회 |
| 합계 | 32회 |

크레딧샵 18종 가운데 12종이 캐시 목록과 겹칩니다. 겹치는 품목과 낱개·묶음은
검색을 따로 만들지 않습니다. 본인 서버·타서버 호가도 같은 검색 결과에서 가져옵니다.

새 검색을 만들 때 횟수를 사용합니다. 결과 페이지 넘김, 입력값 변경, 정렬,
더보기, 크레딧 체크·해제에는 추가 검색을 하지 않습니다.
실패 후 재시도나 만료된 검색을 다시 만들 때는 추가 차감될 수 있습니다.

웹 옥션 검색 한도는 일일 100회이며 자정에 초기화됩니다.
앱 밖의 웹 옥션에서 사용하는 검색도 같은 잔여 횟수에 영향을 줍니다.
[공식 안내](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/394)

## 크레딧을 꺼 놓고 조회했어요. 다시 조회해야 하나요?

1.0.3부터는 체크를 해제해도 크레딧샵 품목을 함께 조회·저장합니다.
나중에 **크레딧 회수 반영**만 켜면 됩니다.

크레딧은 `판매 수수료를 뺀 회수 메소 ÷ 필요한 크레딧`으로 비교합니다.
회수 기준가는 `min(타서버 최저 호가 × 1.1, 본인 서버 최저 호가)`를 사용합니다.
타서버 매물이 없음을 확인하면 본인 서버 가격을 쓰고, 비교 자체를 확인하지 못한 가격은 계산에서 제외합니다.

구버전에서 저장한 시세에 타서버 정보가 없으면 크레딧이 반영되지 않을 수 있습니다.
다음 정상 시세 조회에서 비교값이 확인되면 반영됩니다.
메포 선물식은 크레딧 회수 반영 대상이 아닙니다.

## ‘표본 평균’과 ‘≥’는 무슨 뜻인가요?

최근 3일 전체를 확인하지 못한 경우입니다.
`≥ 120건`이면 확인한 거래가 적어도 120건이라는 뜻입니다.
확인된 표본으로 계산할 수 있는 평균은 ‘표본 평균’으로 표시하고 회수율에도 반영합니다.
전체 거래의 평균·건수와는 차이가 있을 수 있습니다.

페이지 누락이나 날짜 오류 등으로 계산 근거가 부족하면 ‘평균 미확정’으로 표시합니다.

## 품목 옆의 ‘주의’는 왜 붙나요?

본인 서버 호가가 관세를 고려한 타서버 가격보다 비싸거나,
최근 체결이 적거나, 호가가 체결 평균보다 높은 경우입니다.
표시에 마우스를 올리면 그 품목에 해당하는 이유와 기준을 볼 수 있습니다.
주의 표시는 판매 속도를 보장하거나 확정하는 판단은 아닙니다.

## 메차트 조회 실패·갱신 지연이 떠요.

메소마켓 시세를 가져오지 못했거나, 메차트에서 제공한 시세가 오래된 경우입니다.
기존 입력값은 유지합니다. 필요하면 메차트에서 현재 매수가를 확인해 직접 입력해 주세요.
경매장 품목 조회와는 별개입니다.

## 앱을 다시 켜면 조회를 또 해야 하나요?

같은 계정·서버·캐릭터로 연결하면 저장 시세를 불러옵니다.
크레딧 체크를 켜거나 입력값만 바꿀 때는 새 조회가 필요 없습니다.
가격을 최신으로 바꾸고 싶을 때 **시세 조회**를 누르면 됩니다.

## 오류를 제보하려면 무엇이 필요한가요?

[이슈 등록](https://github.com/9root3/maple-mvp-releases/issues/new)에서
앱 아래에 표시된 버전, 어떤 버튼을 눌렀는지, 화면에 나온 오류 문구를 알려 주세요.
스크린샷을 보낼 때는 계정과 캐릭터 정보 등 개인정보를 가려 주세요.
