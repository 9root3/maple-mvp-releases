# 안내 이미지

이 폴더의 화면은 딸깍엠작 1.0.3의 실제 UI에 문서용 예시 데이터를 넣어 촬영했습니다.
실제 사용자의 계정·로그인 화면·시세 조회 결과를 사용하지 않았습니다.
화면의 캐릭터명·가격·거래 건수·검색 잔여 횟수는 실제 값이 아닙니다.

- `dashboard.png`: 조회 결과와 회수율
- `connection.png`: 첫 실행 시 로그인·연결 확인 버튼
- `settings.png`: 시세·할인율·수수료 입력
- `credit.png`: 크레딧 회수 비교 목록 일부

실제 앱의 배치나 입력 방식이 바뀌면 해당 이미지를 함께 갱신합니다.
메소 주머니와 품목 이미지의 권리는 NEXON에 있습니다.
