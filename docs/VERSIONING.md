# 버전 규칙

[처음으로](../README.md) · [릴리스 목록](https://github.com/9root3/maple-mvp-releases/releases)

`1.0.3`처럼 **큰 변경.기능 추가.오류 수정** 순서로 붙입니다.
[SemVer](https://semver.org/lang/ko/)를 기준으로 합니다.

| 바뀐 내용 | 다음 버전의 예 |
| --- | --- |
| 기존 기능 오류 수정, 작은 표시 수정 | 1.0.3 → 1.0.4 |
| 기존 사용자와 호환되는 새 기능 추가 | 1.0.3 → 1.1.0 |
| 기존 설정·데이터·사용 방식과 호환되지 않는 변경 | 1.x.x → 2.0.0 |
| 별도 시험판 | 1.1.0-beta.1 |

정식 버전에는 beta를 붙이지 않습니다. 시험판은 사전 릴리스로 구분하며,
일반 사용자의 자동 업데이트에는 정식 버전만 제공합니다.

한 번 공개한 설치 파일은 같은 버전 번호로 바꿔 올리지 않습니다.
오류를 수정했다면 새 번호로 배포합니다.
README·사용법·품목 목록만 갱신할 때는 앱 버전을 올리지 않습니다.
