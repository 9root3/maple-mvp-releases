# MapleStory item artwork

Original MapleStory item icons are copyright NEXON Korea Corporation and are not covered by this repository's MIT license.
Sources include NEXON's official game guides and the MapleStory.IO game-resource API.
The files are unchanged. Per-image sources, item IDs/regions/versions where available, dimensions and SHA-256 hashes are recorded in sources.json.
They identify MapleStory items in the unofficial Maple MVP fan application. This application is not affiliated with NEXON.
